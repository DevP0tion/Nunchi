# nunchi topic — 세션 주제 보기·바꾸기

주제는 기억을 묶는 단위이고, 주제마다 작업공간(폴더)이 붙는다. 이 스킬의 일은 **이 세션의 주제를 `nunchi_topic` 도구로 확인하거나 바꾸는 것**이다. 주제의 수정·삭제는 대시보드 WorkSpace 탭에서만 가능하다.

## 공통

- `session_id`는 SessionStart가 컨텍스트에 주입한 값(`[nunchi] 이 세션 id: ...`)을 쓴다. 직접 만들거나 추측하지 않는다.
- `set`의 결과 텍스트(주제 블록)가 곧 새 주제 주입이다. 그대로 따르고 같은 내용을 되풀이해 설명하지 않는다.

## 절차

1. **인자가 없다** (`/nunchi:topic`) — `nunchi_topic(action: list)`로 주제 목록을 보여 주고, 현재 세션에 맞는 것을 사용자가 고르게 한다. 고르면 `nunchi_topic(action: set, name, session_id)`를 실행한다. 주제를 해제하려는 요청이면 `action: clear`.
2. **인자가 있다** (`/nunchi:topic 대시보드 UI`, "주제를 X로") — 바로 `nunchi_topic(action: set, name: X, session_id)`를 실행한다.
3. **이름에 맞는 주제가 없다** — `set`이 "주제 없음"으로 실패하면 `list`에서 비슷한 이름을 제시한다. 비슷한 것도 없거나 사용자가 원하면 **새로 만들지 먼저 묻는다.** 승낙해야만 `create`(이름·설명·작업공간 폴더) 후 `set`한다. 사용자 요청 없이 주제를 만들지 않는다.

## 하지 말 것

- 주제 삭제·수정을 시도하지 않는다 (대시보드 전용 — 도구가 열려 있지 않다).
- 사용자가 요청하지 않았는데 주제를 바꾸지 않는다.
